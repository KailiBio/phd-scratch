# phd-scratch

Personal scratch scripts and analysis code, mirrored from `weng-lab/Kaili`.

## Contents

- `bimodal_TF_in_ubi-rDHS/` — analysis of bimodal transcription factor binding in ubiquitous rDHS regions
- `CTCF_and_OCR/` — CTCF binding and open chromatin region analysis
- `DailyCode/` — general-purpose one-off scripts (BED/bigWig conversion, GC content, GENCODE GTF processing, etc.)
- `ENCODE4_matrix/` — scripts for generating ENCODE rDHS binary/signal matrices
- `IDEAS_ChromHMM/` — IDEAS/ChromHMM chromatin state modeling
- `other/` — miscellaneous scripts (enhancer calling from ChromHMM, mm10 RNA-seq, Juicer runs)
- `regions_for_testing/` — test region scripts
